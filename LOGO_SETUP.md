# Логотип Protogen Bot

Основной логотип сайта находится в `static/my_avatar.png`.

Он автоматически используется в:
- левом меню панели;
- странице входа;
- главной странице;
- блоке AI;
- карточках интерфейса.

Чтобы заменить логотип в будущем, достаточно заменить `static/my_avatar.png` на новый квадратный PNG.
