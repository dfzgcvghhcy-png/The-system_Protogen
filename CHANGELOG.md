# Protogen — обновление 2: 8 новых функций

1. **Настройки для каждой группы** — `/settings` в чате показывает кнопки-переключатели: AutoMod, капча,
   ограничения новичков, фильтры, «Гб», итоги недели, AI-модерация, лимит варнов, действие после лимита,
   срок мута. Меняют только этот чат; Web-панель задаёт значения по умолчанию для всех. «↺ Сбросить» возвращает общие.
2. **Голосование за бан «Гб»** — ответь «Гб» (или `/gb`) на сообщение. Кнопки «Бан / Оставить», голоса
   участников с 3+ сообщениями, админов и модераторов так не забанить, 30 минут на голосование,
   порог голосов — в `/settings`. «Гб инфо», «Гб стоп» (модераторы).
3. **Лог-канал** — `/setlog`: все наказания, автомодерация, голосования, удаления у новичков и изменения
   настроек дублируются в отдельный закрытый канал.
4. **Фильтры и автоответы** — `/filter слово ответ` (фразы в кавычках, `{name}`), `/filters`, `/stop`;
   **запрещённые слова** `/banword казин*` — сообщение удаляется, автору варн (с автомутом по лимиту).
5. **Ограничения новичков** — первые N минут после входа (по умолчанию 60) удаляются ссылки, пересылки и медиа.
   Включается в `/settings`.
6. **Итоги недели** — по воскресеньям в 20:00 бот публикует топ активных, благодарности, лидера по уровню
   и сводку модерации. В любой момент: `/week`.
7. **Автобэкап базы** — каждый день в 04:00 файл бэкапа приходит Создателю в личку (нужен `CREATOR_TELEGRAM_ID`),
   `/backup` — сразу. Восстановление: `python tools/restore_backup.py файл.json.gz`.
8. **Вход в панель через Telegram** — кнопка на странице входа → бот присылает в личку
   «Подтвердить вход» с IP и браузером. Работает для аккаунтов с привязанным Telegram ID
   (Создатель — автоматически по `CREATOR_TELEGRAM_ID`).

Также: корректная работа за прокси хостинга (https-ссылки, проверка Origin).

# Protogen — большое обновление (ноябрь 2026)

## Запуск и хостинг
- Новый `server.py`: сайт и бот работают **в одном процессе** (один бесплатный сервис вместо двух).
- Режим **webhook** для Render: Telegram сам будит уснувший сервис. На VPS/ПК — polling.
- `/healthz` для пингов, `render.yaml`, `.env.example`, инструкция `DEPLOY.md`.
- Ссылка на сайт больше не захардкожена (была старая ссылка Railway) — берётся из `SITE_URL` / Render.
- Сообщения, пришедшие пока бот был выключен, теперь обрабатываются, а не теряются.

## Удобные команды
- `/help` — меню с кнопками по разделам вместо стены текста.
- Меню «/» в Telegram заполняется автоматически: отдельно для личных чатов, групп и админов.
- Модерация по **ответу, @username или ID**: `/ban @vasya 1d реклама`, `/mute 30m флуд`.
- Сроки в любом виде: `30s`, `10m`, `10м`, `2ч`, `1d`, `1д`, `1w`, `навсегда`. `/ban` тоже бывает временным.
- Команды **без слеша** (ответом): `мут 10м`, `бан`, `варн флуд`, `кик`, `размут`, `разбан`, `снять варн`.
- Кнопки «Снять варн / Размутить / Разбанить» прямо под сообщением о наказании.
- Новое: `/me` (карточка: уровень, репутация, место в топе), `/id`, `/ping`, `/settings`,
  `/clearwarns`, `/ai` + ответы AI в личке, «+» или «спасибо» ответом = +1 репутации.
- `/start` в личке: кнопки «Добавить в группу», «Команды», «Панель», «Сайт».

## Исправленные ошибки бота
- Имена с символами `<`, `>`, `&` ломали ответы бота (Telegram отклонял сообщение) — всё экранируется.
- Команды в личке (`/notes`, `/rules`, `/warns` и др.) падали с ошибкой — теперь объясняют, что нужна группа.
- **Модераторы из `/setmod` не могли модерировать** — проверка шла только по админам Telegram. Теперь работает матрица прав из Web-панели.
- **Любой участник мог нажимать кнопки `/panel`** и листать пользователей — теперь только модераторы, и только участников своего чата.
- Ручные варны не доходили до лимита (автомут срабатывал только у AutoMod) — теперь лимит работает везде.
- Счётчик варнов был общим на все чаты — теперь в каждом чате свой.
- Репутацию можно было накручивать бесконечно — теперь 1 голос в день за человека.
- AI-чат (`///Протоген`) не был подключён к боту вообще — подключён, работает в фоне и не тормозит бота.
- `/weather` замораживал всего бота на время запроса — вынесено в фон.
- `/rules` и `/welcome` теряли переносы строк.
- Повторные нажатия кнопок панели вызывали ошибку «query already answered».
- Капча при входе выдавала новичку все права (включая закреп) — теперь обычные права участника.
- Бот делал запрос к Telegram на **каждое** сообщение (проверка статуса) — теперь кэш на 2 минуты.
- Изменить правила/приветствие через матрицу с уровнем 0 мог бы любой — теперь минимум админ.

## Сайт
- Статистика на главной всегда показывала 0 и OFFLINE (не было API) — добавлены `/api/public/stats`, `/api/public/servers`, `/api/public/health`.
- CPU/RAM/PING на главной были **случайными числами** — заменены на реальные: статус бота, задержка БД, пинг, аптайм.
- Админка на компьютере открывалась в «мобильном режиме Telegram» без бокового меню — исправлено.
- В дашборде статусы «Telegram API / OpenAI ONLINE» были нарисованы всегда зелёными — теперь реальные.
- «Топ пользователей» в дашборде никогда не заполнялся — теперь заполняется. «Действия сегодня» считались за всё время.
- Публичный веб-чат с AI тратил ваш ключ без ограничений — лимит 6 сообщений в минуту на посетителя.
- Картинки сжаты в WebP: ~13 МБ → ~1 МБ, страницы грузятся в разы быстрее. Оригиналы — в `assets_src/`.
- Кнопка «Добавить в группу», favicon, описание для поисковиков и превью ссылок.
- Из каталога команд убраны несуществующие (`/gb`, `/whois`, `/banlist`…), добавлены новые.
